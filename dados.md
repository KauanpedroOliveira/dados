# Dashboard Produtos Madeireiros - SFB

Projeto desenvolvido para análise OLAP e ETL utilizando Apache Hop e React.js.

## Tecnologias

- Apache Hop
- React.js
- Recharts
- CSV
- GitHub

## ETL

Foram realizados:
- tratamento de valores nulos
- conversão de tipos numéricos
- cálculos de métricas
- exportação dos dados tratados

## OLAP

Conceitos aplicados:
- Slice
- Drill-down
- Roll-up

## Dashboard

O dashboard apresenta:
- Preço Médio Unitário
- Impacto da Inflação
- Ticket Médio por Segmento
